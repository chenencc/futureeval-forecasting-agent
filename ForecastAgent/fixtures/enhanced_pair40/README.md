# Frozen identical-body comparison inputs

These eight gzip JSON files contain the public original evidence text archived
from run `37086283246`: 20 binary and 20 nonbinary questions, five per batch.
No API keys, model outputs or resolution labels are included. The original
acquisition response blobs and HTTP headers are omitted. Exact body hashes,
character offsets, packet hashes and parent bundle hashes preserve provenance.

The fixtures restore experiment portability because the earlier GitHub
artifacts are no longer listed. They are frozen inputs, not new collection.
Both routes see the same complete original-body library, question, decision
registry and response types. Only the bounded passage selection changes.

Mercury Decide makes at most two physical attempts per route, four per question,
160 over the entire cohort. Failed attempts remain consumed. Both routes retain
a validated first result if the conditional second call is unavailable. Calls
alternate route order across questions. Each batch uploads its own journals.

Date cases without authoritative platform scales remain research distributions;
they are not certified submission payloads. Current saved bodies and model
knowledge may contain outcomes: this is a retrospective paired diagnostic,
not a leakage-free forecasting backtest.

Model inference never reads scoring labels. Evaluation must freeze and audit
all inference outputs before loading labels from the separate local dataset.
