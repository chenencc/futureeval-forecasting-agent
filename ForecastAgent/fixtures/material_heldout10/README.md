# Held-out material review snapshots

Ten archived task snapshots, excluded from the material-gap repair cases, are
restored byte-for-byte from the local SHA-256 store. The frozen experiment
manifest is `ForecastAgent/experiments/MATERIAL_HELDOUT10.json`; it records each
original run, artifact, path, source hash, compressed fixture hash and two
material requirements. Some original remote artifacts have already been pruned
after local archival, so Actions restores these verified fixtures.

This is a saved-evidence acquisition acceptance experiment, not fresh collection
and not a leakage-free forecasting backtest. Dates in these historical questions
do not limit the capture time of the saved documents. Only question rules, needs
and saved source windows enter the material reviewer. No forecast output or
resolution labels are requested.

The workflow preserves initial model journals and decisions and permits at most
one additional review decision per question, bounded by remaining cumulative
capacity. Legacy bundles without capacity metadata retain default ceilings.
Search, fetch and submission credentials/tools are absent. A new review-only
execution has a 300-second window and does not reset HTTP or decision counts.
Initial failed-capture records remain visible in raw integrity diagnostics.

The same new model response is evaluated with axes-only and guarded closure
rules. This isolates the program gate effect; it does not compare two model
prompt versions. Actual recall, false closure and false rejection rates require
manual inspection of each declared target material and remain unset until then.
