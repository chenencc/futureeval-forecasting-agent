# Prospective common-original trial

Run one fresh native acquisition/map loop per unresolved question, including the
independent release supplement. Freeze that resulting package and the selected
literal evidence once. Mercury receives either those originals alone or the same
originals plus the accepted map. Registry, target instructions and evidence
selection are identical. Alternate arm order. Never submit either prediction.

Use one to five explicit question-only parents and keep read-only official status
receipts outside provider inputs. Each case retains 12 collection decisions,
16 physical Super attempts (including failures), two model failures, 900 collection
seconds, three Tavily basic attempts, one Exa attempt, eight initial capture
reservations, one basic Extract batch, three map revisions, and the existing
two-HTTP/two-browser independent supplement caps. Each scoring arm gets one
physical Mercury attempt. Re-entry uses completed caches and remaining ledgers;
there is no automatic retry, quota reset, model switch or forecast submission.

All current source-view, incremental-patch, bounded-delivery and critical-gap
receipt policies are enabled explicitly. Common evidence uses the existing
22,000-byte target-first pack, with the remaining scoring allowance reserved for
map notes. Hidden map observations are counted. Decoded-view coordinates cannot
silently become raw-body coordinates. If no literal observation is deliverable,
the mapped arm uses the exact original-only state and is marked as a fallback,
not a successful map comparison. Supplement additions are recorded separately
from native source-to-map feedback. Pending source reviews remain gaps.

```text
python -m ForecastAgent.research_loop.prospective_trial \
  --parents frozen-parents.json --root new-prospective-trial
```

Preparation makes no provider requests. Add `--execute --limit-cases 1` for the
first case, then omit the limit to finish the frozen list. Original acquisition
cost is shared; report it separately from the two scoring arms. Preserve valid
payloads, timestamps, raw replies, hashes, graph events, receipts and failures.
Unresolved questions have no accuracy score yet. Compare binary Brier and
nonbinary distributions only after official resolution. This trial can measure
mechanical closure and cost now; it cannot establish calibrated causal meaning,
fair historical backtesting or a predictive advantage before outcomes exist.
