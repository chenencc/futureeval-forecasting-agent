# Intelligent acquisition V1: initial validation

Date: 2026-10-05. Baseline: release `v1.0.1` (`c9bfab4`).

## Completed checks

- Thirteen targeted offline regressions passed.
- The complete offline suite passed: 449 tests.
- Forty-seven frozen analysis, competition, and model transport dependencies
  match their release repository hashes, allowing Git CRLF checkout normalization.
- CLI preflight returns the frozen identity with zero provider requests.
- A mocked run exercises the actual collector loop: plan, one primary discovery,
  original source capture, complete table header/row banking, adequacy annotation,
  and closure. Re-execution returns its completed state without another model call.
- A forced supplement interruption resumes the same frozen parent without
  recollection. Invalid rule bindings, stale source versions, invented excerpts,
  critical requirement removal, incomplete scopes, and package tampering fail
  closed or remain explicit gaps. Assessment bookkeeping cannot extend material
  progress or grant budget.

Tests use mocked provider calls; mock decisions and elapsed times are not actual
Ultra/Super inference, throughput, cost, or source-relevance evidence.

this original-parent audit.

The new autonomous agent has not been run on these historical tasks, and they
were not recollected or scored. The audit confirms compatible saved-source input
and motivates separate capture/banking/visibility diagnostics. It does not measure
new discovery recall, relevance, model reliability, or forecast quality.
