# Release eager original capture

This collection-only adapter is adapted from prediction-market v0.3.4. It runs
on the v1.0.5-recovery.2 release base. Mercury prompts, conditional rereading,
typed distributions, probability clipping and platform delivery stay frozen.

## Sequence

1. Super freezes the normal material plan and selects a basic discovery query.
2. The existing Tavily or Exa handler saves the actual discovery receipt.
3. The program captures at most two observed primary/detail pages before the
   next Super request. These reads use the existing eight native reservations.
4. At least two native slots remain for subsequent Agent choices. Failures and
   interrupted reservations are never free; repeated URLs are not retried.
5. Existing free browser/Extract and independent supplement routing runs with
   its original budgets. No search or model request is added by this adapter.
6. A separate export annotates source roles and confirmed navigation shells.
   Short official notices, tables and uncertain markup remain available.
7. The existing Mercury original-evidence analysis consumes that export.

Only literal links observed in saved markup are added. One document-link layer
is allowed; private-address validation stays in the native transport. An
official hostname, heading match or readable page does not establish relevance,
truth, complete coverage or absence of an event.

## Preservation

Raw collector state and its original package are unchanged by the final export.
Small timestamped packet indexes reference content-addressed source objects.
First/final capture clocks, source hashes, failures and excluded shells remain
auditable. Replays preserve the exact input, implementation and reservations.
Historical tasks cannot perform eager live captures. Old active collection
directories cannot be migrated or silently granted new quotas.

The rollout uses a new immutable release variant. Accepted submissions remain
terminal; rollout preflight requires no existing active collection. The market
worker, credential choices and market-specific admission/price heads are not
changed by this transfer.

## Acceptance

Run `python -m unittest ForecastAgent.tests.test_eager_capture` plus existing
source-reading, release, recovery, typed-distribution and delivery tests.
The five-question paired material replay uses the same frozen question, observed
search leads, source bytes and native fetch allowance. It tests capture scheduling
and conservative source admission; it is not a forecast-accuracy backtest.

The October 14 replay used five saved Metaculus MiniBench questions: ECDC West
Nile countries (46074), BIST100 (46075), GPT announcements (46078), La Jolla
water level (46091), and TEPCO robotic-arm suspension (46079). It reused recorded
search leads and Agent read choices. Fifteen control-readable originals were
retained; two additional saved originals were admitted. Missing corpus bodies
remain explicit replay gaps. No live search, model call, newly observed access
failure, skill improvement or controlled forecasting A/B result is claimed.
