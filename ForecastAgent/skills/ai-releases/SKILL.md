---
name: ai-releases
description: Research exact AI model releases and benchmark leaderboard versions.
---

Distinguish model announcement, limited preview, public API availability and open-weight publication. Record exact model ID, version, release channel and access restrictions. For benchmarks identify the designated leaderboard, subset, metric, agent configuration, tie rule and snapshot time. Current ranks are not historical ranks. Save the source body and relevant rows; report unverified historical versions as a gap. A developer's own benchmark statement is not equivalent to inclusion on a designated independent board.
