description: Identify entities and resolution requirements before collecting evidence.
---

Freeze the subject identity, jurisdiction, event window and every resolution condition. Prefer sources explicitly designated by the question. Separate event time, announcement time, effective time and observation availability. Build critical needs that can be independently checked. A failed search cannot prove absence. Use plan_evidence and real source URLs; do not infer outcomes from resolved-question context.

Read useful resolution-source URLs before spending the frozen lifetime Tavily budget shown by the runtime. Default to three basic searches: designated primary sources, independent reporting, then a specific remaining gap. Only the collection_v2 profile permits calls four and five, and only with recent or official_gap roles; existing three-call tasks retain their original limit. Use general for official records, news for reporting and finance for economic data; do not restrict broad primary-source discovery to news. A current official homepage may lead to a specific release or RSS feed; use only captured links.

Use the tools exposed by the current runtime. In collection_v2 and collection_v3, batch accepted URL reads and targeted paragraph queries with read_sources, then pass the returned passage_id and need_ids into record_excerpts. Do not enter coordinates. collection_v3 keeps the three-search cap. Older profiles may expose find_passages and search_saved_text instead. Preserve relevant paragraph or table context. Never save navigation as substantive material. Basic Extract is one optional paid rescue batch for important failed URLs, not another search.

Call plan_channels after the evidence plan to estimate shared HTTP allocation. Prefer designated data endpoints before general pages for numerical questions. Archive replay needs two attempts; preserve them when essential. The local reader handles long paragraphs, Unicode queries, table rows and bounded neighboring text. Model context is projected from the task state and complete recent tool turns; use read_document or read_dataset_rows for omitted text rather than repeating a search.

Historical collection_v2 defaults to verified pre-cutoff bodies. A current body is saved for audit but cannot be read or excerpted without a verified local capture or collect_archive replay. The archive lookup and replay each consume one shared HTTP attempt. No archive means a gap, not permission to use current Wikipedia or a live release log. Date-bounded structured data is a current vintage with revision caveats, not a historical snapshot. Use list_dated_datasets, collect_dataset and read_dataset_rows for exchange OHLC, North Atlantic SST and exact SEC forms. SEC issuer discovery is not exhaustive for private companies; use only discovered CIKs. Missing future observations are not collection gaps. Use general, not finance, for climate and scientific data.

Inspect the checkpoint included in the runtime context before finishing; call collection_checkpoint only when explicitly exposed. Consider supported official adapters and a short Polymarket entity/event query while HTTP budget remains. Store rules and display prices separately, without equivalence or edge calculations. Record concrete channel deferrals; do not spend a call merely to check a box. Acquisition gaps are missing material, not assertions that an event has not happened.
