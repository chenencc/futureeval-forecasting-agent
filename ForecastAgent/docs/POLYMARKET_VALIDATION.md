# Polymarket 专项验证

日期：2026-09-30。执行入口：`python -m ForecastAgent.verify_polymarket`。

公开只读接口：[Gamma public-search 文档](https://docs.polymarket.com/api-reference/search/search-markets-events-and-profiles)。不需要 Tavily 或模型调用。

## 真实测试

使用 `fixtures/retrieval_2026_five.json` 中五道题，每题分别用完整题干、实体关键词搜索。保留当前市场原始响应，重放同一份数据比较修改前后。另用两个真实子合约的完整标题再次搜索，并通过 `/markets/{id}` 独立检查 condition ID、YES token ID 和标题。

| 原题 | 本次结果 |
|---|---|
| Royal Mail 邮费 | 旧版误收五个法国总统选举子合约；修复后这五个候选全部排除 |
| Anthropic 公开 S-1 | 搜到 IPO/估值候选。核读第一候选规则后确认要求上市开始交易，明确排除仅公告或提交文件；不是原题的等价合约 |
| 全美大陆飓风、9月1日前 | 搜到州级飓风、11月底前候选，时间和地域均不同；不能直接使用其概率 |
| 30年国债整个8月保持≥5% | 旧版实体搜索返回五个年份冲突且相关度低的候选，包含5年期合约；修改后均排除 |
| DJIA 成分调整 | 本次两种查询均未留下相关候选 |

十份搜索响应，候选总条数由30降为20（含重复查询的重复候选，不代表20个独立合约）。两个同合约正例均搜索成功，分数1.0，详情页身份字段一致。累计14个公开 GET：10个搜索、2个正例搜索、2个详情读取。复跑使用缓存，新增调用0。

单元测试：Polymarket 11项，完整套件65项通过。覆盖子合约选择、年份冲突、未交易0.5价格、反向 No/Yes、非二元或坏价格、token对应、重复合并、关闭合约过滤、错误报价、历史截止阻止实查，以及等价核对门槛。

## 修复

- 年份冲突不能绕过相关性门槛。
- YES价格及token按outcomes位置读取，要求真实Yes/No二元结果；拒绝坏价格、错位token和交叉报价。
- 同时读取event嵌套合约和顶层合约，按ID去重。
- 搜索结果保留原始响应、响应哈希、接口、采集时间、分页信息；允许传入实体查询，仍按完整题干评分。
- 所有候选 `eligible_for_edge=false`；必须核对实体、事件阶段、时间与时区、阈值与量词、地域、解析源。
- 传入过去的 `as_of_utc` 时拒绝当前价格查询，返回 `historical_snapshot_required`。

## 尚未验证和限制

这是当前市场发现测试，不是历史回测。五道原题的历史截止时间不能赋给现在采集的价格。没有确认任何可用于计算edge的等价合约。

相关性评分仍是词面筛选，不是语义解析；IPO/估值等相关事件仍可能成为待核对候选。API只取第一页，有 `hasMore=true` 时不能断言全市场没有合约。当前关闭合约被过滤，因此历史题无结果也可能因已关闭。

匹配调用仍位于旧 `main.py`，新版 retrieval 工具注册表未接入。此报告不声称赛题监听已自动完成Polymarket匹配。

完整快照与报告在 `snapshots/polymarket-verification/`，不提交大体积原始响应到仓库。报告含每题修改前后候选、规则、价格、身份字段和快照路径。
